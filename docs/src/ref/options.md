# Command-line Options

The supported options vary by build and version. To see the exact options available in the current executable, run:

```sh
auto-editor --help
```

Options are declared in [`src/cli.nim`](../../../src/cli.nim), and their behavior is handled by the command-line entry point in [`src/main.nim`](../../../src/main.nim).
